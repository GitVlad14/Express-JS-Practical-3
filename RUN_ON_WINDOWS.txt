Практична робота 3 - запуск у Windows 10 / VS Code

1. Розпакуйте ZIP, відкрийте папку Practical_3_Express_Sharovskyi у VS Code.
2. У терміналі виконайте: npm.cmd test
3. Виміряйте покриття: npm.cmd run coverage
4. Початкове покриття (тільки завантаження модуля): npm.cmd run baseline
5. За замовчуванням тести перевіряють збережений знімок utils.js із практичної 1.
6. Для перевірки саме локального Express.js у PowerShell введіть:
   $env:EXPRESS_UTILS_PATH="C:\Users\vlads\VSProjects\express\lib\utils.js"
   npm.cmd run coverage
   Remove-Item Env:EXPRESS_UTILS_PATH
7. У реальному Express.js може бути інша версія залежностей. Тести ізольовано підмінюють сторонні бібліотеки контрольованими реалізаціями - це unit characterization, не інтеграційне тестування.
8. Прикріпіть на платформу PDF-звіт, а до GitHub - вихідний код тестів, конфігурацію і результати.
9. Для академічної доброчесності прочитайте пояснення підозрілих результатів та сформулюйте власний висновок.
